## アプリ概要

アプリ名：栞灯

コンセプト：**忘れたくない感情に、栞を挟もう。価値観でつながる、静かな共有。**

本アプリは、自分の心を動かした一文を記録し、自分の価値観を見直すためのアプリです。
読書、映画、音楽等自分の心が動いたときに開いて記録すると、振り返った時に自分の価値観に気づくきっかけになったり、自分を救ってくれるかもしれません。
他の人の一文を見ることで新しい価値観に気づくきっかけを与えます。

## 個人的な目標

Rails×Docker×DBを使ってRails入門の復習アプリを作成する

## アイデアが生まれたきっかけ

SNSでアニメ名言集を眺めていて、何かのきっかけで印象に残った一文が自分の心を助けてくれる時があるよなとふと思い出しました。就活の自己分析等を通じて、自分のターニングポイントとして思い出すときに浮かんでくる一文があったり、心のどこかである時の一文を基準にしていたり…
普段から心を動かされた一文を記録しておくと、自分の価値観を振り返るきっかけになったり、力になることがあるだろうと思い、このアプリを作成することにしました。

## 課題の整理

１自己分析が就活をはじめ、キャリアを考える上でも重要だというが、何から手を付けてよいのかわからない。

２学びや気づきを残したいという気持ちはあるが、SNSやメモ帳、ノートに記録すると、
　- どこに書いたか忘れる
　- 検索性が悪い
　- 他人の反応が気になりすぎる
　- すぐに記録できない
　‐ 振り返る機会がない
　等のデメリットがある。

## 想定ユーザーについて

- メイン層：自己研鑽や内省をしたい・大切にしている人
　　　　　読書家、アニメ・映画・音楽好き
　　　　　「良い言葉を聞いたけど、忘れてしまう・記録しておきたい」という悩みを持つ人
- サブ層：クリエイターや発信者
  　　　　自分の感性を磨きたい人、SNSで共感を得たい人
    
- ペルソナ    
    本、漫画、アニメの名言に救われた経験がある。
    自分の「軸」を言葉にして残しておきたいが、既存のSNSだと流れてしまうし、メモ帳だと味気ないと感じている
    

## 既存サービス・競合調査

| **比較対象** | **課題（ペインポイント）** | **本アプリの差別化戦略** |
| --- | --- | --- |
| **SNS (X, Instagram)** | 情報が流れて消えてしまう。他人の「いいね」や反応が気になり、本音を書きにくい。 | **「ストック型」かつ「内省重視」。** 自分の価値観を蓄積することに特化し、バズりよりも「自分への気づき」を優先する。 |
| **読書・映画管理アプリ** | 作品全体の感想が主。一文単位での記録や、感情に基づいた検索が弱い。 | **「一文」という最小単位に特化。** 作品単位ではなく、心に刺さった「言葉」そのものを主役に。 |
| **汎用メモアプリ** | どこに何を書いたか忘れ、読み返さない。ただの「情報の墓場」になりがち。 | **「再会」をデザインする。** ログイン時の「今日の一文（ランダム表示）」により、過去の自分と出会う体験を仕組み化する。 |

## このサービスで提供したい価値

- 「自分軸」の可視化
    
    言葉が貯まるほど、「自分はこういう言葉に惹かれる人間なんだ」という一貫性が見えてくる
    
- 感情の「お守り」
    
    落ち込んだ時に、自分が過去に感銘を受けた言葉だけを見返せる「心の救急箱」になる
    
- 価値観のレコメンド
    
    「自分の好きな一文」と「他人の好きな一文」がタグで繋がることで新しい作品と出会える
    
- 日常の栞として
    
    記録して終わりではなく出典・ジャンル・感情を明記する
    また見直したいと思った時のインデックスとしての機能を強化
    
- 低負荷なアウトプット
    
    長文レビューを書くのはハードルが高い
    投稿の手軽さを追求することで、日常生活のあらゆる瞬間（移動中のアニメ、寝る前の読書など）を記録の対象にできます。
    

## 懸念点とその対策

- 入力が面倒
    - 他の人が入力している一文は候補を出す
- 継続性
    - 今日の一文等のコンテンツを充実させる
- 出会いの演出をどうするか
    - 単なるSNSではなく、自己の振り返り
    ‐ 出会いのための演出を考える

## 作成する機能
### MVP

- ユーザー認証（新規登録、ログイン、ログアウト機能）
- 一文投稿機能（一文、出典、タグ、コメント）
- 一覧機能

### Should

- タイムライン機能（全ユーザーの投稿を一覧表示）
- ランダム機能（ログイン時に今日の一文をランダム表示）
- ランダム機能（今の気持ちに合ったタグからランダムで一文表示）

### could

- お気に入り機能（一覧表示も…）
- リポスト機能（自分のコレクションとして保存）
- マイページ（統計）
- 検索機能

## 画面構成

- ログイン画面　MVP
- ユーザー登録画面　MVP
- 設定画面　MVP
- トップ画面（道しるべ）    
    中央：過去の自分の記録が浮かぶ
    私の栞箱：過去の自分を紐解く
    栞を挟む：投稿画面へ
    遠くの灯火：誰かの心の跡をたどる　タイムライン画面へ
    設定：設定画面へ    
- 投稿画面　MVP    
    一文入力欄
    出典
    ジャンル
    感情タグ
    メモ
    記録ボタン（しおりを挟む）    
- マイページ（書庫）　Could
    カレンダー表示：投稿した日に灯がともる
    タグクラウド：どんな感情を記録しているのか可視化
- タイムライン（言葉の森）Could
    他の人の一文が表示
